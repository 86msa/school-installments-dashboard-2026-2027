# لوحة إحصائيات أقساط المدرسة 2026–2027

تطبيق محلي لويندوز يعرض إحصائيات الطلاب والأقساط والوصولات من قاعدة بيانات برنامج المدرسة. يقرأ القاعدة دون تعديلها، ويعرض ديون سنة 2025–2026 بصورة منفصلة عن أقساط 2026–2027. لا يتضمن المستودع قاعدة بيانات المدرسة أو سجلات الطلاب أو إعدادات الجهاز.

## الوظائف

- نظرة عامة تعرض إجمالي الأقساط والمقبوض والمتبقي، مع مخططات التحصيل الشهري وحالة السداد والتحصيل حسب الصف.
- كشوف الطلاب والوصولات والديون، مع البحث متعدد الكلمات والفلترة بحسب الصف والحالة والمبلغ والتاريخ حسب القسم.
- تقارير تفصيلية قابلة للتصدير إلى جداول إكسل، وملفات نصية، وملفات قابلة للطباعة.
- معاينة قبل الطباعة مع اختيار الاتجاه العامودي أو الأفقي، وطباعة ملف الطالب أو القسم الحالي. تشمل طباعة النظرة العامة مخططاتها.
- إعدادات لاختيار قاعدة البيانات، وتغيير اسم المدرسة الظاهر في الواجهة وعناوين الطباعة، والشعار والألوان، وإنشاء نسخة احتياطية.
- تثبيت على ويندوز مع اختصار على سطح المكتب وقائمة ابدأ.

## التثبيت

حمّل ملف التثبيت من صفحة الإصدارات، ثم شغّله على ويندوز. بعد فتح التطبيق، اختر قاعدة بيانات برنامج المدرسة من الإعدادات. يحتاج قارئ القاعدة إلى بقاء ملف برنامج المدرسة الأصلي في المجلد الأب لمجلد قاعدة البيانات، كما هو في ترتيب البرنامج الأصلي. قد يحتاج بعض الأجهزة إلى مكوّن قراءة قواعد البيانات القديمة.

يحتفظ التطبيق بالإعدادات ضمن بيانات مستخدم ويندوز. تغيير اسم المدرسة من داخل التطبيق يغيّر اسمها الظاهر في القائمة وعنوان النافذة والتقارير؛ ويبقى اسم اختصار التثبيت عامًا.

## تشغيل المشروع من المصدر

يتطلب بيئة تشغيل جافاسكربت وحزم المشروع، إضافة إلى ويندوز للوصول إلى قاعدة البيانات الأصلية.

```powershell
npm ci
npm start
```

لإجراء الاختبارات أو إنشاء ملف تثبيت جديد:

```powershell
npm test
npm run build:win
```

## الخصوصية والبيانات

يعمل التطبيق محليًا على الجهاز ولا يرسل بيانات الطلاب إلى خدمة خارجية. ملفات قواعد البيانات، والنسخ الاحتياطية، والإعدادات المحلية، ولقطات الشاشة التي تحتوي سجلات فعلية مستبعدة من المستودع. تُنشر ملفات التثبيت في صفحة الإصدارات، لا ضمن سجل الشيفرة.
