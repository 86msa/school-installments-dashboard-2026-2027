# لوحة إحصائيات أقساط المدرسة 2026–2027

تطبيق محلي لويندوز يعرض إحصائيات الطلاب والأقساط والوصولات من قاعدة بيانات برنامج المدرسة. يقرأ القاعدة دون تعديلها، ويعرض ديون سنة 2025–2026 بصورة منفصلة عن أقساط 2026–2027. لا يتضمن المستودع قاعدة بيانات المدرسة أو سجلات الطلاب أو إعدادات الجهاز.

## الوظائف

- نظرة عامة تعرض إجمالي الأقساط والمقبوض والمتبقي، مع مخططات التحصيل الشهري وحالة السداد والتحصيل حسب الصف.
- قسم مستقل للخصومات يعرض الطلاب المستفيدين، ومبلغ خصم كل طالب ونسبته وسببه من قاعدة البيانات، مع البحث بالسبب والفلترة حسب الصف ونطاق النسبة، والطباعة والتصدير.
- بطاقات لإجمالي الخصومات وعدد المستفيدين ونسبتهم، ومخططان للخصومات من إجمالي الأقساط ولتوزيعها حسب الصف، ويظهران في طباعة النظرة العامة.
- كشوف الطلاب والوصولات والديون، مع البحث متعدد الكلمات والفلترة بحسب الصف والحالة والمبلغ والتاريخ حسب القسم.
- تقارير تفصيلية قابلة للتصدير إلى جداول إكسل، وملفات نصية، وملفات قابلة للطباعة.
- معاينة قبل الطباعة مع اختيار الاتجاه العامودي أو الأفقي، وطباعة ملف الطالب أو القسم الحالي. تشمل طباعة النظرة العامة مخططاتها.
- إعدادات لاختيار قاعدة البيانات، وتغيير اسم المدرسة الظاهر في الواجهة وعناوين الطباعة، والشعار والألوان، وإنشاء نسخة احتياطية.
- تثبيت على ويندوز مع اختصار على سطح المكتب وقائمة ابدأ.
- شريط جانبي بعرض أصغر، وجداول تتكيّف مع المساحة دون تمرير أفقي. يجمع كشف الخصومات البيانات المرتبطة في سبعة أعمدة، وتظل تفاصيل التصدير والطباعة كاملة.

## التثبيت

حمّل ملف التثبيت من [صفحة الإصدارات](https://github.com/86msa/school-installments-dashboard-2026-2027/releases)، ثم شغّله على ويندوز. بعد فتح التطبيق، اختر قاعدة بيانات برنامج المدرسة من الإعدادات. يحتاج قارئ القاعدة إلى بقاء ملف برنامج المدرسة الأصلي في المجلد الأب لمجلد قاعدة البيانات، كما هو في ترتيب البرنامج الأصلي. قد يحتاج بعض الأجهزة إلى مكوّن قراءة قواعد البيانات القديمة.

يحتفظ التطبيق بالإعدادات ضمن بيانات مستخدم ويندوز. تغيير اسم المدرسة من داخل التطبيق يغيّر اسمها الظاهر في القائمة وعنوان النافذة والتقارير؛ ويبقى اسم اختصار التثبيت عامًا.

## تشغيل المشروع من المصدر

يتطلب بيئة تشغيل جافاسكربت وحزم المشروع، إضافة إلى ويندوز للوصول إلى قاعدة البيانات الأصلية.

```powershell
npm ci
npm start
```

لإجراء الاختبارات أو إنشاء ملف تثبيت جديد:

```powershell
npm test
npm run build:win
```

## توقيع ملف التثبيت وتنبيه ويندوز

ملف التثبيت المنشور حاليًا غير موقّع رقميًا، لعدم توفر شهادة توقيع معتمدة. لذلك قد يعرض ويندوز تنبيه «قام ويندوز بحماية الكمبيوتر» أو «ناشر غير معروف». تغيير ألوان أو أسماء ملف التثبيت لا يزيل هذا التحذير. التوقيع المعتمد يثبت هوية الناشر، وقد تستمر تحذيرات البرامج الجديدة إلى حين اكتساب سمعة كافية، بحسب [وثائق مايكروسوفت](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

أُضيف أمر بناء موقّع لا ينجح إلا إذا تم توقيع الملفات. عند توفر شهادة معتمدة، تُضبط بياناتها في متغيرات البيئة التالية خارج المستودع:

```text
CSC_LINK
CSC_KEY_PASSWORD
```

ثم يُشغّل الأمر:

```powershell
npm run build:win:signed
```

ملفات الشهادات ومفاتيحها مستبعدة من المستودع. لا تتضمن النسخة أي تعديل يعطل حماية ويندوز.

## الخصوصية والبيانات

يعمل التطبيق محليًا على الجهاز ولا يرسل بيانات الطلاب إلى خدمة خارجية. ملفات قواعد البيانات، والنسخ الاحتياطية، والإعدادات المحلية، ولقطات الشاشة التي تحتوي سجلات فعلية مستبعدة من المستودع. تُنشر ملفات التثبيت في صفحة الإصدارات، لا ضمن سجل الشيفرة.
